# Soul Plugins

Коллекция специализированных плагинов для серверов Minecraft (Paper 1.21+).

## Почему Soul?

Название линейки вдохновлено атмосферой и философией хардкорных игр вроде Elden Ring и Dark Souls, где качество, проработка деталей и отсутствие компромиссов стоят на первом месте. 

Рынок переполнен шаблонными и плохо оптимизированными решениями, которые не позволяют серверам предложить уникальный опыт. Серия плагинов **Soul** создавалась с одной целью — изменить это. Вместо стандартных и серых интерфейсов — современный визуальный стиль с анимациями и MiniMessage-градиентами, вместо перегруженного кода — высокая производительность и асинхронная работа с базой данных. Это премиальные, отточенные инструменты для тех проектов, которые хотят дать своим игрокам только лучшее.

## Список плагинов
### SoulAuction
* **Ссылка:** [SoulAuction](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulAuction)
* **Описание:** Аукцион для Paper 1.21+ и Folia: несколько витрин на одной сети, разная экономика на каждый аукцион, GUI с поиском и защита сделок без fat-jar.
* **Основные функции:**
  * Мульти-аукционы (`/ah`, `/ah sell`, hub «мои лоты / claim / история»); валюты Vault, PlayerPoints, XP, CoinsEngine, предметы.
  * Категории, сортировки, избранные продавцы и лоты, bulk sell, превью шалкера; MiniMessage, PlaceholderAPI.
  * MySQL + Redis на прокси: общий каталог, distributed lock, атомарные покупки; оффлайн-выплаты продавцу в БД.
  * Налоги, лимиты слотов по правам, TTL лотов, claim; Discord/Telegram; админ history/audit/recover.
### SoulCrates
* **Ссылка:** [SoulCrates](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulCrates)
* **Описание:** Кейсы для Paper 1.21+ и Folia: premium-анимация, pity, reroll, multi-open и синхрон ключей по сети — без fat-jar и без дюпов на открытии.
* **Основные функции:**
  * Несколько типов кейсов (`crates/*.yml`): веса наград, pity, broadcast редких дропов, preview/confirm, cooldown и права per-crate.
  * Анимация из 3 фаз (key insert → CSGO spinner → firework); ModelEngine, idle-дисплеи на блоках, голограммы (TextDisplay / DecentHolograms).
  * Виртуальные и физические ключи, `/sc shop` (Vault), `/sc givekey`; reroll с free/paid rolls; bulk open x5/x10.
  * Привязка к блоку (`/sc setcrate`) и Citizens NPC (`/sc setnpc`); Shift+RMB — preview, RMB — открытие.
  * MySQL + Redis на прокси: зеркало virtual keys и pity; session lock и consume ключей до анимации.
  * In-game редактор наград, `/sc stats`, PlaceholderAPI (`%soulcrates_*%`), API-события фаз открытия.
### SoulEvents
* **Ссылка:** [SoulEvents](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulEvents)
* **Описание:** Ядро для серверных ивентов: общий API, сессии, планировщик, каталог схематик, защита от абуза и статистика в SQLite.
* **Основные функции:**
  * Модули отдельными JAR: **AirDrop** (сундуки с неба, wave-defense), **Volcano** (извержения и лут в воздухе), **MobWaves** (разломы, волны мобов, супербоссы).
  * Gate, LootGuard, ArenaGuard и EffectResolver — инвиз/полёт на арене, кулдаун лута, запрет постройки и жидкостей, иммун к дебафам.
  * SchematicService: paste / undo / scan `.schem` через FAWE; общий каталог `plugins/SoulEvents/schematics/`.
  * Автоспавн типов по интервалу, `/soulevents reload` перезагружает core и все модули.
  * Накопительная статистика (убийства, лут, сундуки) и плейсхолдеры PlaceholderAPI (`%soulevents_*%`).
### SoulBlast
* **Ссылка:** [SoulBlast](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulBlast)
* **Описание:** Плагин кастомной динамитной взрывчатки с детальной настройкой разрушений.
* **Основные функции:**
  * Шесть готовых пресетов зарядов с разным типом урона (для обсидиана, осушения жидкостей и т.д.).
  * Интеграция с ProtectionStones (урон по приватам, прочность регионов, голограммы прочности).
  * Поддержка CoreProtect для логирования и асинхронного отката взрывов (#soulblast).
  * Гримуар (GUI-каталог) для покупки динамитов за опыт, валюту или ванильный TNT.
  * Система Decay для постепенного разрушения и ручного ремонта блоков песком.
### SoulBuyer
* **Ссылка:** [SoulBuyer](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulBuyer)
* **Описание:** Продвинутый скупщик ресурсов: живое GUI, динамический рынок, ротация ассортимента и прогрессия игрока — из коробки ~380 предметов.
* **Основные функции:**
  * `/buyer` — сетка с ценами и рынком; ЛКМ «продать всё», ПКМ выбор количества, фильтры, сортировки, «продать всё».
  * Живой рынок: массовые сдачи снижают коэффициент, decay возвращает к норме; ротация ассортимента по таймеру с оповещением в чат.
  * Vault и PlayerPoints — обычный и донатный скупщик (`/donbuyer`); автопродажа (подбор / меню / сундук) и магазин бустеров.
  * Очки прогрессии, XP категорий, дневные лимиты на item-id, VIP-множители; панель статистики и PlaceholderAPI в меню.
  * Хранение flat / SQLite / MySQL + Redis для сети; async I/O, secure storage; публичное API `SoulBuyerApi` для других плагинов.
### SoulDart
* **Ссылка:** [SoulDart](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulDart)
* **Описание:** *В разработке.* Летающий снаряд из Display-блоков — игрок запускает объект, он летит в цель и бьёт мобов или игроков.
* **Основные функции:**
  * Сборная 3D-модель из block display (без entity-мобов) — лёгкая анимация полёта на Paper 1.21+.
  * Запуск в сторону цели: PvE и PvP, урон и попадание по траектории.
  * Настройка формы, скорости, урона и кулдауна в config (планируется).
  * Мемный визуал для фан-серверов; ядро — обычный кастомный projectile, не тяжёлый фреймворк.
### SoulDrone
* **Ссылка:** [SoulDrone](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulDrone)
* **Описание:** Доставка предметов между игроками через анимированного фиолетового дрона — без телепорта вещей командой.
* **Основные функции:**
  * `/drone <игрок>` (алиасы `/send`, `/posylka`): сборка дрона, меню груза, вылет к получателю с звуками и подписью над моделью.
  * Запрос accept/deny у получателя, `/drone toggle` — отключить приём; оффлайн-посылки в SQLite с `/drone claim` / `refuse`.
  * Автовозврат отправителю, если получатель не забрал посылку в срок; Shift+ПКМ — просмотр груза без изменений.
  * Опционально Vault (стоимость отправки) и WorldGuard (запрет в мирах/регионах); настройка внешности, таймаутов и GUI в config.
### SoulFix
* **Ссылка:** [SoulFix](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulFix)
* **Описание:** GUI-ремонт снаряжения с красивым визуальным сопровождением и экономикой.
* **Основные функции:**
  * Интерактивное меню починки предметов с отображением прогресса в BossBar и эффектами.
  * Докупка дополнительных слотов ремонта за валюту (Vault / PlayerPoints) с ростом цены.
  * Настройка лимитов слотов и кулдаунов по группам привилегий.
  * Встроенные кулдауны на ремонт и интеграция с PlaceholderAPI.
### SoulGrace
* **Ссылка:** [SoulGrace](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulGrace)
* **Описание:** Персональный процедурный паркур для каждого игрока с автоматической генерацией трассы.
* **Основные функции:**
  * Изолированная генерация блоков в небе индивидуально для каждого участника.
  * Динамическая трасса: предыдущий блок исчезает при переходе на следующий.
  * Ловушки на реакцию (обвал платформы, появление блока сзади) и настройка сложности.
  * Поддержка наград за этапы/финиш, проверка времени прохождения и интеграция с PlaceholderAPI.
### SoulHolo
* **Ссылка:** [SoulHolo](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulHolo)
* **Описание:** Персональные голограммы для игроков, привязанные к их регионам WorldGuard.
* **Основные функции:**
  * Полная настройка (текст, цвета, сдвиг, масштаб, фон) через GUI-интерфейс.
  * Работает на нативных TextDisplay (Paper API), не требуя сторонних плагинов на голограммы.
  * Автоматическое добавление строки с подписью владельца для контроля за спамом.
  * Гибкие лимиты на число голограмм и длину строк в зависимости от донат-группы.
### SoulKeep
* **Ссылка:** [SoulKeep](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulKeep)
* **Описание:** GUI-система сохранения выбранных предметов после смерти игрока.
* **Основные функции:**
  * Выбор защищаемых предметов перетаскиванием в интерфейсе /keepsoul.
  * Сохранение предметов в SQLite БД при смерти и автоматический возврат после респавна.
  * Шанс сохранения настраивается индивидуально для типов предметов или наследуется от прав.
  * Разблокировка дополнительных слотов защиты через донат-права.
### SoulMark
* **Ссылка:** [SoulMark](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulMark)
* **Описание:** Система репутации игроков с управлением через GUI.
* **Основные функции:**
  * Открытие меню по Shift + ПКМ по игроку или командой /soulmark.
  * Простое выставление лайков и дизлайков (+1/-1 репутации) с кулдауном.
  * Логирование в SQLite БД и поддержка плейсхолдеров PlaceholderAPI для отображения репутации.
### SoulNPC
* **Ссылка:** [SoulNPC](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulNPC)
* **Описание:** Простые лёгкие NPC-статуи для хабов и точек входа — без тяжёлых фреймворков, с упором на меню по клику.
* **Основные функции:**
  * Статичные фигуры игроков (скин, поза, имя) — минимальная нагрузка, много NPC на спавне без лагов.
  * ПКМ по NPC открывает привязанное меню, команду или действие — удобно для магазинов, телепортов и справки.
  * Создание и правка через команды/GUI админа; хранение в конфиге, перезагрузка без рестарта.
  * Без ИИ и лишней логики — только то, что нужно для «живого» интерфейса на карте.
### SoulPact
* **Ссылка:** [SoulPact](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulPact)
* **Описание:** Модульная клановая система на базе MiniMessage и SQLite/MySQL.
* **Основные функции:**
  * Легковесное ядро: профили, роли, права участников, баннеры, клановая почта и дома.
  * Модульная архитектура: подключение аддонов (казна, сундуки, земли WorldGuard, войны, квесты, Discord-вебхуки).
  * Gladiator: автоматические PvP-ивенты на аренах по расписанию для выявления сильнейшего клана.
  * Leaderboard: живые топы (таблички, стойки с броней, голограммы TextDisplay) с автоматическим обновлением.
  * Документированное API расширений для создания собственных модулей.
### SoulRecycle
* **Ссылка:** [SoulRecycle](https://github.com/b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0b0/SoulRecycle)
* **Описание:** GUI-переработка предметов обратно в ресурсы: превью до подтверждения, ванильные рецепты и scavenge — «сломал → получил материалы».
* **Основные функции:**
  * Двухфазное меню: воронка → превью выхода → лаймовый краситель; ESC возвращает предмет в инвентарь.
  * Auto-recipe по крафту верстака + ручные overrides; policy зачарований/прочности, scavenge (поломка, книги чар).
  * Vault-комиссия, скидки `soulrecycle.discount.*`, bypass только по праву; чёрный список материалов.
  * `/recycle`, `/recycler`, `/soulrecycle` — GUI, reload, list, test; anti-dupe через InventoryHolder.
